# Bible by Midvash (Claude plugin)

This branch holds only the Claude plugin: the manifest, the `scripture-lookup`
skill and the connection to the remote MCP server at
`https://mcp.midvash.com/mcp/plugin`. No key, no local code.

The server's source lives on the [`main` branch](https://github.com/midvash/bible-mcp).
